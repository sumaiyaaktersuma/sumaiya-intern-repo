# Focus Bear App Testing Feedback

## Key Issues
1. **Checkbox Confusion** – Tapping a task (e.g., "Drink a glass of water") plays a video instead of simply checking it off. This feels unintuitive to me as a first time user.  
[water drinking video](image-8.png)
2. **Unclear Onboarding** – No quick intro explaining how habits + videos work.  
[no intro section](image-9.png)
3. **Button Wording** – “Continue Drink a glass of water” sounds awkward.  
4. **No Visible Progress** – Finishing tasks doesn’t show clear progress (bar, %).  
[no bar for progress](image-10.png)
5. **Priority Email Scan** – It's just countdown showing for 5 min. there should something like clock or something intersting rather than plain white screen. 
[email scan](image-11.png) 
6. **intersting part** (image-5.png)
After completing these task I felt active and productive which I really liked the most.
##  Suggested Improvements
- Separate task completion from video playback.  
- Add a short onboarding guide (3–4 steps).  
- Improve button text (e.g., “Next: Drink a glass of water”).  
- Show progress tracking during rituals.  
- Give feedback if someone stop using the app for a long time.
- There should be a survay for each user to check what more they need on the app.
